## Y deposer une copie, si on veut le dossier autonome

Rien ne se met a jour tout seul : une copie deposee ici est figee au jour ou
elle a ete exportee, et le document en ligne, lui, continue de bouger. Pour en
deposer une malgre tout :

1. ouvrir le document avec le lien ci-dessus ;
2. bouton d'export en haut a droite -> PDF (ou Word) ;
3. deposer le fichier ici ;
4. `git add`, `git commit`, `git push`.

Seul le document qui a change est a re-exporter, pas les quatre.
